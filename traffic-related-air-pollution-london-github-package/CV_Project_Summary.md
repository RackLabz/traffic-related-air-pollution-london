# CV / Portfolio Summary

## Traffic-Related Air Pollution Exposure in London

Integrated 757K+ air-quality observations with London traffic and spatial data to investigate PM2.5 and NO₂ patterns using statistical analysis and machine learning. Built a group-aware modelling workflow across unseen monitoring deployments, compared linear and nonlinear models, tuned Random Forest models with group-aware cross-validation, and performed residual and permutation-importance analysis. Final tuned Random Forest models achieved R² of 0.622 for PM2.5 and 0.542 for NO₂ on deployment-level holdout data.
