# Data

Raw datasets are intentionally not committed to this repository.

Download the source data from the official London Datastore pages:

- Breathe London AQMesh pods:
  https://data.london.gov.uk/dataset/breathe-london-aqmesh-pods-2r401

- London Atmospheric Emissions Inventory (LAEI) 2022:
  https://data.london.gov.uk/dataset/london-atmospheric-emissions-inventory-laei-2022-2lg5g

Expected working files:

- meta_data.csv
- stationary_data.csv
- LAEI2022-major-roads-flows-and-speeds.xlsx
- LAEI2022-minor-roads-flows-and-speeds.xlsx

The notebook documents the data preparation and integration process.
